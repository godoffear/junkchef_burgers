# 🍔 Burger Shop Nha Trang

Полнофункциональное приложение для управления микроресторана по доставке бургеров в Нячанге, Вьетнам.

## ✨ Возможности

### 1. **Управление сменами**
- Начало и завершение смены
- Ввод продаж по каждому блюду в реальном времени
- Автоматический расчёт расходов товаров с учётом отходов
- Вычисление себестоимости и маржи за смену
- История всех смен

### 2. **Учёт товаров**
- Отслеживание остатков по всем товарам
- Автоматическое вычитание товаров при завершении смены
- Визуальные алерты (красное/жёлтое/зелёное) при достижении минимумов
- Ручное редактирование остатков

### 3. **Рекомендация закупок**
- Расчёт на основе средних продаж за предыдущие дни
- Учёт сезонности (понедельник-вторник слабее, выходные сильнее)
- Автоматический расчёт потребности с учётом % отходов
- Список закупок с суммой и единицами измерения

### 4. **Финансовая аналитика**
- Обзор выручки и себестоимости за неделю
- Расчёт маржи по каждому блюду
- Разбор по категориям товаров (сырьё, упаковка, прочее)
- Вычисление потерь на отходы

### 5. **Двойная валюта**
- VND (вьетнамский донг) — основная валюта
- RUB (рубль) — для ведения на родине
- Мгновенный переключатель валют
- Курс: 1 VND = 0.0025 RUB

### 6. **Экспорт**
- PDF экспорт отчётов, смен и списков закупок
- Готовые к печати документы
- Историческое сохранение

### 7. **Офлайн работа**
- LocalStorage для полной работоспособности без интернета
- Все данные хранятся локально
- Синхронизация при восстановлении соединения

## 🚀 Как использовать

### Начало дня
1. Откройте вкладку **"Смена"**
2. Нажмите **"▶ Начать смену"**
3. Приложение запомнит время начала

### Во время смены
1. Вводите кол-во проданных блюд
2. Нажимайте **"Сохранить продажи"** после каждого ввода
3. Следите за предварительным расходом товаров
4. Видите маржу в реальном времени

### Завершение смены
1. Нажмите **"⏹ Завершить смену"**
2. Система автоматически:
   - Запишет продажи за день
   - Вычислит расходы с учётом отходов
   - Вычтет товары из остатков
   - Покажет итоги

### Проверка остатков
1. Вкладка **"Товары"** показывает текущие остатки
2. 🔴 Красное — ниже минимума
3. 🟡 Жёлтое — приближается к минимуму
4. 🟢 Зелёное — норма

### Расчёт закупок
1. Вкладка **"Закупки"**
2. Нажмите **"🔄 Рассчитать закупки"**
3. Система покажет:
   - Среднее кол-во продаж в день
   - Прогноз на неделю
   - Список товаров к закупке с суммой
4. Экспортируйте в PDF

## 💡 Примеры расчётов

### Себестоимость Классического бургера
```
Булка 75г × 800₫/кг = 60₫
Фарш 200g × 280₫/кг = 56₫
Огурец 20g × 15₫/г = 300₫
Помидор 15g × 20₫/г = 300₫
Салат 10g × 25₫/г = 250₫
Соус 30ml × 2₫/ml = 60₫
Коробка = 3,000₫
───────────────
Сумма = 4,026₫

С отходами (+18% за огурец, помидор, булку, фарш):
Реальная себестоимость = ~4,700₫

Продаём за 165,000₫
Маржа = (165,000 - 4,700) / 165,000 = 97.1%
```

### Отходы картофеля за неделю
```
Если продадим 100 порций фри в день:
- Расход: 250g × (1 + 20%) × 100 = 30,000g = 30kg
- Отходы: 30kg × 20% = 6kg
- Потеря: 6kg × 12₫/g = 72,000₫ за день

За неделю: 72,000 × 7 = 504,000₫ на одни отходы!
```
